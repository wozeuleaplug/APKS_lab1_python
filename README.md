## Короткий опис проєкту
Цей проєкт демонструє використання спеціалізованого **AI-агента (Build Engineer)** для автоматизації повного циклу розробки кросплатформеного Python-застосунку Hello World.

Агент керує процесами створення структури проєкту, налаштування віртуального середовища (`venv`), тестування за допомогою `pytest`, а також автоматичного виконання CI/CD процесів у **GitHub Actions** для Windows, Linux та macOS.
